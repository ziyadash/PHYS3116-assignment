# PHYS3116-assignment

## Overview
In this project, we chose to explore **Option 1 - Accreted Milky Way Globular Clusters**. Using data from the (Harris Catalogue of Milky Way globular clusters)[https://physics.mcmaster.ca/~harris/mwgc.dat] and (van den Berg et al. (2013))[https://ui.adsabs.harvard.edu/abs/2013ApJ...775..134V/abstract],
our task is to use stellar population (metallicities [Fe/H] and ages) and dynamical information to identify potentially accreted globular clusters. We must also consider if there are some globular clusters that stand out in the age-metallicity relation or that do not rotate with the bulk of other globular clusters.
